Introduction

Cub3D is a 42 School project implementing a raycasting engine inspired by Wolfenstein 3D.

Technologies

  • C Language
  • MiniLibX Graphics
  • Math Library (trigonometry)

Raycasting Explained

Raycasting creates 3D perspective by casting rays from the player's viewpoint and calculating wall intersections. Unlike raytracing, raycasting only checks intersections along a 2D plane, making it faster for real-time rendering.

Field of View: 60°

The project uses a 60° FOV for natural perspective similar to human vision.

Fish-Eye Correction

Perpendicular distance removes distortion: dist_perpo = distance × cos(ray_angle - player_angle)

DDA Algorithm

Digital Differential Analysis finds ray-wall intersections efficiently in a grid-based map.

Key Functions

  • facing_player() - Determines ray direction (up/down/left/right)
  • horizonlat_inter() - Finds horizontal grid line intersections
  • vertical_inter() - Finds vertical grid line intersections
  • dda_algo() - Compares distances and chooses closest hit

Direction Detection

// Facing up: π < angle < 2π
// Facing right: angle < π/2 OR angle > 3π/2

Distance Calculation

distance = sqrt((x2-x1)² + (y2-y1)²)

Wall Rendering & Projection

Wall Height Calculation

dist_perpo = distance × cos(ray_angle - player_angle)
wall_height = (TILE_SIZE / dist_perpo) × dist_proj_plan
wall_begin = (WIN_HEIGHT / 2) - (wall_height / 2)
wall_end = (WIN_HEIGHT / 2) + (wall_height / 2)

Texture Selection

  • Horizontal hit + facing up → North texture (NO)
  • Horizontal hit + facing down → South texture (SO)
  • Vertical hit + facing left → West texture (WE)
  • Vertical hit + facing right → East texture (EA)

Texture Mapping

tex_x = hit_position % TILE_SIZE
tex_y = (y - wall_start) × (64.0 / wall_height)

Key Constants

  • TILE_SIZE: 64 - Grid cell size
  • WIN_WIDTH: 1920 - Window width
  • WIN_HEIGHT: 1080 - Window height
  • NUM_RAYS: 1920 - Rays per frame
  • MOVE_SPEED: 2 - Player movement speed
  • ROTATION_SPEED: 0.02 - Rotation speed

Main Rendering Loop

FOV = 60° (π/3 radians)
dist_proj_plan = (WIN_WIDTH / 2) / tan(FOV / 2)
For each of 1920 rays:
  - Cast ray at angle
  - Run DDA algorithm
  - Calculate wall height
  - Select texture
  - Draw vertical slice
